Aero Pressure Calc PWA — комплект для розміщення

Розмістіть усі файли з цієї папки на HTTPS-хостингу для статичних сайтів. Потім відкрийте HTTPS-посилання в Safari на iPhone, натисніть Поділитися → На початковий екран. Відкрийте додану іконку один раз онлайн, щоб зберегти ресурси для офлайн-роботи, а потім перевірте в авіарежимі.

Якщо відкривати index.html безпосередньо з програми «Файли», офлайн-встановлення PWA не працюватиме надійно.
